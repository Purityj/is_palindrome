# Welcome to is_palindrome_purityj

is_palindrome_purityj is a simple Python package that checks whether a given
string is a palindrome, ignoring case and non-alphanumeric characters.

## Get started

You can install this package into your preferred Python environment using pip:

```bash
$ pip install is-palindrome-purityj
```

To install from TestPyPI:

```bash
$ pip install --index-url https://test.pypi.org/simple/ 
            --extra-index-url https://pypi.org/simple \
            is-palindrome-purityj
```

## Usage

```python
from is_palindrome_purityj import is_palindrome

is_palindrome("A man, a plan, a canal: Panama")
#True
```
